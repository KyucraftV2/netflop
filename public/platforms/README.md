# Logos des plateformes

Utilisés **uniquement** sur les tuiles et les écrans de chaque plateforme, pour l'identifier.
Les noms et logos sont des marques de leurs propriétaires respectifs. Netflop n'est affilié à
aucun d'eux.

`primevideo.svg`, `disneyplus.svg`, `arte.svg`, `tf1plus.svg` et `m6plus.svg` sont de
simples marques texte (pas les logos officiels) : remplace-les par les logos officiels si
leur licence le permet.

Le logo TMDB (`public/tmdb.svg`) est le logo officiel fourni par TMDB pour l'attribution
([conditions](https://www.themoviedb.org/about/logos-attribution)).

Pour ajouter une plateforme : dépose son logo ici (SVG conseillé) et référence-le dans
`lib/platforms.ts` (`logo`, `tileColor`).
